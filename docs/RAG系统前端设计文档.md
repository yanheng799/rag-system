## 2. 页面设计

### 2.1 知识库管理页（`/datasets`）

映射端点：

| 方法 | 路径 | 用途 |
|------|------|------|
| POST | `/api/v1/datasets` | 创建知识库 |
| GET | `/api/v1/datasets` | 知识库列表（分页） |
| GET | `/api/v1/datasets/{dataset_id}` | 知识库详情 |
| PATCH | `/api/v1/datasets/{dataset_id}` | 更新知识库 |
| DELETE | `/api/v1/datasets/{dataset_id}` | 删除知识库 |

**交互说明：**

- 拖拽上传区域（Drag & Drop），支持多文件批量上传，文件类型限制 `.pdf / .docx / .xlsx`，单文件上限 50MB
- 上传后文档自动出现在"待处理文档"列表，状态为 `pending`
- "开始解析选中"按钮位于"待处理文档"标题右侧；无选中项时按钮禁用（disabled）；选中后点击调用 `POST /api/v1/documents/ingest`，同时传递分块设置参数
- **分块设置区域**：位于待处理文档列表下方，默认折叠，点击"展开高级设置"展开
  - **分块策略**：单选按钮组，4 种策略（段落/标题/固定大小/逐页），默认选中"段落分块"，每种策略附带简要说明
  - **高级设置**（折叠）：最大分块字符数（默认 1024）、最小分块字符数（默认 50）、重叠字符数（仅固定大小策略时启用）、垂直间距阈值（仅段落策略时启用）
  - 点击"开始解析选中"时，将当前分块设置打包为 `chunk_options` 对象传入 API
- 解析期间轮询 `GET /api/v1/documents/{doc_id}/status`，文档从 `processing` → `done` / `failed`
- `failed` 状态的文档显示错误信息，提供"重试"按钮（再次调用 ingest）
- `done` 状态的文档显示"查看分块"链接，跳转至分块管理页
- 删除操作弹出确认对话框

**会话列表侧边栏（左侧）：**

- 顶部"新对话"按钮，点击创建空白会话并切换到右侧
- 会话列表按时间倒序排列，每个会话项显示：
  - 会话标题（自动取首条问题内容，最多显示 20 字符，超出截断）
  - 最后活跃时间（今天/昨天/具体日期）
  - 当前活跃会话高亮标记（`●`）
- 会话项支持右键菜单或滑动操作：**重命名**、**删除**
- 会话历史存储在浏览器 `localStorage`，按 `query_sessions` 键存储，结构：

```json
      "messages": [
        {
          "role": "user",
          "content": "什么是 MixedChunk？",
          "timestamp": "2024-03-01T14:30:00"
        },
        {
          "role": "assistant",
          "content": "MixedChunk 是一种支持文本和表格元素交错的数据结构...",
          "total_ms": 1230,
          "sources": [
            {
              "metadata": { "chunk_id": "...", "filename": "handbook.pdf", "page": 12, "score": 0.87 },
              "elements": [...]
            }
          ],

        }
      ]
    }
  ],

```

- 切换会话时，右侧对话区域立即渲染该会话的完整历史消息
- 删除会话弹出确认对话框，确认后从 `localStorage` 移除

**对话区域（右侧）：**

- 顶部显示当前会话标题，支持点击编辑重命名
- 消息按时间顺序从上到下排列，用户消息靠右，助手消息靠左
- 输入框固定在对话区域底部，支持 `Enter` 发送、`Shift+Enter` 换行
- 筛选条件折叠在输入框上方：知识库下拉（`dataset_ids`）、文档下拉（`doc_ids`）、`top_k` 数字输入
- 发送后按钮变为加载状态（Loading spinner），禁用重复提交
- 回答区域使用 `aria-live="polite"` 实时更新
- 回答下方展示引用来源卡片，包含文件名、页码、分块索引、相关性分数
- 来源卡片中的长文本使用 `line-clamp` 截断，点击展开查看完整内容
- 每条回答显示总耗时（`total_ms`）
- 新消息到达时自动滚动到底部；用户手动上滚时暂停自动滚动，显示"跳到最新"按钮

### 2.4 分块管理页（`/chunks`）

映射端点：

| 方法 | 路径 | 用途 |
|------|------|------|
| GET | `/api/v1/documents/{doc_id}/chunks` | 分块列表（分页） |
| GET | `/api/v1/chunks/{chunk_id}` | 分块详情 |
| PUT | `/api/v1/chunks/{chunk_id}` | 编辑分块文本 |
| DELETE | `/api/v1/chunks/{chunk_id}` | 删除分块 |
| POST | `/api/v1/chunks/merge` | 合并分块 |
| POST | `/api/v1/chunks/{chunk_id}/split` | 拆分分块 |
| POST | `/api/v1/chunks/link` | 关联分组 |
| POST | `/api/v1/chunks/unlink` | 取消关联 |

#### 2.4.1 分块列表视图

```

│  ← 返回文档    分块管理 — handbook.pdf                         │
├───────────────────────────────────────────────────────────────┤
│                                                               │
│  ┌─ 批量操作栏 ─────────────────────────────────────────────┐ │
│  │ 已选择 2 个分块                                          │ │
│  │ [合并选中] [关联分组] [取消关联] [删除]                      │ │

│                                                               │
│  ☐  分块类型  页码  索引  字数   预览                    分组   │
│  ─────────────────────────────────────────────────────────── │
│  ☐  text     1     0    512   MixedChunk 是一种支持...   ─     │
│  ☐  text     1     1    340   full_text 字段用于向量...   ─     │
│  ☐  mixed    2     0    800   | 列名 | 值 | 说明 |...     g_1   │
│  ☐  text     2     1    256   该系统采用五层架构...      g_1   │

│  ...                                                          │

└───────────────────────────────────────────────────────────────┘
```

**交互说明：**

- 表格支持多选（Checkbox），选中后顶部显示批量操作栏
- 批量操作：
  - **合并**：校验选中分块是否相邻且无间隔，合并后文本不超过 2048 字符
  - **关联分组**：将选中分块归入同一 `group_id`
  - **取消关联**：清除选中分块的 `group_id`
  - **删除**：弹出确认对话框
- 分页参数同步到 URL `?page=1&size=20`
- 点击行进入分块详情
- "分组"列显示 `group_id`（非空时），相同 `group_id` 的分块以颜色标记

**交互说明：**

- 顶部展示分块元数据（ID、类型、页码、索引、字数、分组、创建时间）
- 元素列表按序号展示每个元素，`table` 类型元素提供"查看图片"链接（Signed URL）
- "完整文本"区域为可编辑文本区域（`<textarea>`），支持修改后保存（`PUT /api/v1/chunks/{chunk_id}`）

- "删除"弹出确认对话框
- 保存时自动触发重新向量化，按钮显示加载状态

## 4. Web 界面规范

### 4.1 可访问性（Accessibility）

- 所有图标按钮添加 `aria-label`（删除、编辑、查看等图标）
- 表单控件关联 `<label>`（通过 `htmlFor` 或包裹控件）
- 模态框设置 `role="dialog"` + `aria-modal="true"`，打开时捕获焦点，关闭时恢复焦点
- 聊天回答区域使用 `aria-live="polite"` 实时播报
- 使用语义化 HTML：`<nav>` 导航、`<main>` 主内容、`<ul>/<ol>` 列表
- 标题层级遵循 `<h1>` — `<h6>` 递进，提供跳转主内容的 Skip Link

### 4.2 焦点状态（Focus States）

- 所有交互元素添加 `focus-visible:ring` 样式
- 禁止 `outline: none` 且无替代焦点指示
- 使用 `:focus-visible` 代替 `:focus`（避免点击时出现焦点环）
- 复合控件使用 `:focus-within`

### 4.3 表单规范（Forms）

- 上传区域 `accept=".pdf,.docx,.xlsx"`，文件名输入 `spellCheck={false}`
- 提交按钮在请求期间显示 Spinner，禁止重复提交
- 错误信息显示在对应字段旁，提交失败时聚焦到第一个错误字段
- 表单控件添加 `autocomplete="off"`（非认证场景）
- 未保存修改时触发 `beforeunload` 提示

### 4.4 动画（Animation）

- 遵守 `prefers-reduced-motion` 媒体查询
- 仅动画 `transform` / `opacity`（GPU 合成属性）
- 禁止 `transition: all`，显式列出属性名
- 动画可中断，响应用户输入

### 4.5 排版（Typography）

- 省略号使用 `…`（U+2026）而非三个点
- 加载状态文案以 `…` 结尾："加载中…"、"保存中…"
- 数字列使用 `font-variant-numeric: tabular-nums` 对齐
- 标题使用 `text-wrap: balance` 防止孤字

### 4.6 内容处理（Content Handling）

- 文本容器处理长内容：`truncate`、`line-clamp-*` 或 `break-words`
- Flex 子元素添加 `min-w-0` 允许文本截断
- 处理空状态，不渲染空白 UI
- 用户生成内容需兼容短、中、长三种输入

### 4.7 性能（Performance）

- 分块列表使用服务端分页（默认 20 条，上限 100 条）
- 文档状态轮询仅在活跃解析期间执行，完成后停止
- 引用来源卡片长文本使用 `line-clamp` 截断

### 4.8 导航与状态（Navigation & State）

- URL 反映页面状态：分页 `?page=&size=`、检索模式 `?mode=hybrid`、选中知识库等
- 所有导航使用 `<Link>` / `<a>` 组件，支持 Cmd/Ctrl + 点击新窗口打开
- 破坏性操作（删除知识库、文档、分块）必须弹出确认对话框

## 6. 错误处理

| HTTP 状态码 | 触发场景 | UI 表现 |
|------------|---------|--------|
| 400 | 空问题、不支持文件类型、拆分参数无效 | 字段级内联错误提示 |
| 404 | 资源不存在 | 空状态页面 + "返回" 按钮 |
| 409 | 名称冲突、知识库下有文档未强制删除 | 对话框提示冲突原因 |
| 413 | 文件超过 50MB | 上传区域红色提示 |
| 500 | 服务器内部错误 | 全局 Toast 提示 |
| 503 | 服务不可用 / LLM 调用失败 | 问答区域错误提示 + 重试按钮 |
